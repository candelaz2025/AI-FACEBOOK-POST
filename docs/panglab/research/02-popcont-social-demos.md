## 3. Onboarding และ Brand DNA (V1, V4)

**Empty state** (V4 ~0:10, VERIFIED): หน้าแรกหลัง login มี mascot ก้อนสีน้ำเงิน ข้อความ "ยังไม่มีแบรนด์ — สร้างแบรนด์แรกเพื่อเริ่มสร้างคอนเทนต์ที่ตรงกับแบรนด์" ปุ่มหลัก "+ สร้างแบรนด์" และลิงก์รอง "ลองสร้างโพสต์แรกใน 1 นาที →" ผู้ใช้จึงเลือกได้สองทาง คือสร้างแบรนด์ก่อน หรือข้ามไปสร้างโพสต์เลย

**ขั้น 0: "ตัวช่วยสร้างแบรนด์ — เริ่มจาก 3 คำถาม"** (V1 0:04–0:28, VERIFIED) หัวข้อรองเขียนว่า "ตอบสั้นๆ แล้ว AI จะเติมโปรไฟล์แบรนด์ที่เหลือให้ — แก้ทีหลังได้ทุกช่อง"

| ช่อง | รายละเอียด / microcopy |
|---|---|
| ชื่อแบรนด์ * | placeholder "เช่น Café Bloom" |

| มีรูปร้าน เมนู หรือสินค้าไหม | ไม่บังคับ สูงสุด 4 รูป · "รูปป้ายเมนูหรือป้ายราคาช่วยได้มาก — AI จะอ่านรายการและราคาจากในรูปให้เลย (อ่านไม่ชัดจะเว้นว่างไว้ ไม่เดา) และเก็บรูปไว้ใช้เป็นสไตล์ภาพของแบรนด์ต่อ" |
| สไตล์ภาพ | ไม่บังคับ เปลี่ยนทีหลังได้ |

**ผลลัพธ์ Brand DNA** (V1 ~2:12, VERIFIED) แสดงเป็นเอกสารอ่านอย่างเดียว มี "แนวทางคอนเทนต์" (tagline + ย่อหน้าบรรยายจุดยืน), "Content Pillars" และ "หมวดหมู่คอนเทนต์" แบบลำดับเลข เช่น "1 หิวแล้วกินอะไรดี? · 2 กรอบจริง อร่อยจากกล้วยจริง · 3 Snack Talk" แต่ละหมวดมีคำอธิบาย

**หน้า "จัดการแบรนด์"** (`popcont.ai/brands`, V1 ~2:20, V4 ~0:19, VERIFIED) เป็นการ์ดแบรนด์ที่มีโลโก้, tag หมวด (F&B), "1 สินค้า · 10 โพสต์", สถานะ "ไม่โพสต์ลง Facebook/Instagram" หรือไอคอนเพจที่ผูกไว้, ปุ่ม "แก้ไขแบรนด์" และ "+ แบรนด์ใหม่"

## ผลต่อ PRD

**1. แก้ §4 และ §7.1 เรื่องเครดิต:** PRD เขียนว่า POPCONT ใช้ "1 Credit = 1 Content" และเสนอเครดิตถ่วงน้ำหนักเป็นจุดต่าง แต่ POPCONT ถ่วงน้ำหนักอยู่แล้ว (caption 0.1, ภาพ 1, อัลบั้ม 3, วิดีโอ 3.2, idea 0.1, plan 0.1, Visual DNA 0.5) และเปิดเผยราคาบนทุกปุ่ม ควรแก้ parity matrix แล้วตั้งราคาเทียบรายการต่อรายการ ปัจจุบัน PRD ตั้ง **วิดีโอ 5 เครดิต** แพงกว่า POPCONT (3.2) ราว 56% และ **อัลบั้ม 1+0.5/สไลด์** ถูกกว่าหรือเท่ากับ 3 ขึ้นกับจำนวนสไลด์ ต้องตัดสินใจว่าจะยอมเสียมาร์จินวิดีโอหรือไม่ ส่วน Campaign plan ที่ PRD ให้ฟรี (CAMP-1) ถือเป็นจุดต่างจริง ควรเก็บไว้และเขียนบนหน้าราคาให้ชัด (POPCONT คิด 0.1)

**2. เพิ่ม BRAND-0 "Quick start 3 คำถาม" เป็น P0:** ชื่อ + อุตสาหกรรม + เล่าธุรกิจ 2–3 ประโยค + รูปสูงสุด 4 (อ่านเมนู/ราคาจากรูปด้วย Gemini vision) แล้วให้ AI เติม persona, จุดยืน, tone และสินค้าที่เดาได้ให้ผู้ใช้ติ๊กยืนยัน ทางนี้ทำได้เร็วกว่า BRAND-3 auto-scan URL และ SME ไทยจำนวนมากมีแค่เพจ FB ไม่มีเว็บ จึงควรให้ BRAND-3 เป็นทางเลือกเสริม (scan จากเพจที่เชื่อมแล้ว) ไม่ใช่ทางหลัก

**3. เพิ่มฟิลด์ใน Brand DNA ให้ทัดเทียม:** "คุณขายอะไร: สินค้า/บริการ/ทั้งสอง", เป้าหมายธุรกิจ multi-select, ช่วงราคา, สไตล์ภาษา 6 แบบ (รวม Gen Z Slang และ Thai-Eng Mixed), ช่องทางสั่งซื้อต่อสินค้า (ใช้ปิดท้ายแคปชันโดยไม่เดา), รูปสินค้า 3 มุม และ **Presenter/Mascot สูงสุด 3 คน** (รูป + ชื่อ + บทบาท) ที่เลือกใช้ได้ในทุกโพสต์ ข้อสุดท้ายเป็นฟีเจอร์ที่ POPCONT ใช้ขายหนัก ("น้องโบจัง ประธานบริษัท") ควรยกเป็น P0 หรือ P1 ต้นๆ

**4. Visual DNA เป็น asset ระดับแบรนด์:** ให้มี preset สไตล์ 6–8 แบบ และ "อัปโหลด 3 รูปอ้างอิงแล้ว AI เขียน style prompt" เก็บเป็น `brand.visual_dna` แยกจาก `brand.voice` และ override ได้รายโพสต์ ("มีผลกับโพสต์นี้เท่านั้น") ใน ARCHITECTURE ควรเพิ่มตาราง `brand_presenters` และ `brand_visual_styles` และบันทึก reference image ids ที่ส่งเข้า image model ทุกครั้ง

**5. นโยบาย "ไม่แต่งข้อมูล" ต้องเป็นทั้ง requirement และ microcopy:** เพิ่ม GEN-11 ว่า AI ห้ามสร้างราคา เบอร์โทร LINE ID หรือตัวเลขที่ผู้ใช้ไม่ได้ให้ ถ้าไม่มีข้อมูลให้เว้นว่าง และบังคับใน system prompt พร้อม output validator (regex เบอร์/ราคา เทียบกับ input) POPCONT สื่อเรื่องนี้ในทุกฟอร์ม เพราะเป็นความกังวลหลักของ SME

**6. Campaign Studio:** ปรับ CAMP-1 ให้มี slider เป้าหมาย 5 แกนที่รวม 100% (แทน pillar % แบบกรอกเอง), preset ช่วงเวลา (1 สัปดาห์/3, 2 สัปดาห์/7, 1 เดือน/20), เลือกพรีเซ็นเตอร์และโลโก้ และรองรับ `@mention` asset ในช่องไอเดีย ขั้นที่ 2 ให้เลือก content type รายโพสต์ แสดง credit estimate แยกบรรทัด และสร้างเป็น background job ที่ผู้ใช้ออกจากหน้าได้ (มี badge สถานะใน header) จุดที่ PANGLAB ทำได้ดีกว่า POPCONT: (ก) ปุ่ม "สร้างทั้งหมด" ครั้งเดียวพร้อมยอดรวม POPCONT ต้องกด generate ทีละการ์ด (VERIFIED ในคลิป) และ (ข) approval state ก่อน publish

**7. Calendar และ Library:** POPCONT มีปฏิทินเทศกาลไทย, "วันที่ไม่ควรขาย", drag-to-reschedule และสีจุดตามแบรนด์แล้ว PRD CAL-1 กับ GEN-2 จึงเป็นแค่ parity ไม่ใช่จุดต่าง ควรเพิ่มมุมมอง "คิว" และ filter "คอนเทนต์ที่สร้างค้างไว้" (draft ที่ยังไม่ตั้งเวลา) และแสดงเครดิตที่ใช้บนการ์ด

**8. หน้าโซเชียล:** ทำ mapping แบรนด์ → เพจ/บัญชี โดยให้แบรนด์ใหม่เริ่มที่ "ไม่โพสต์" (ป้องกันโพสต์ผิดเพจ ซึ่งสำคัญมากสำหรับเอเจนซี่ที่มีหลายเพจ) และมี "เพจหลัก (ค่าเริ่มต้น)" ต่อบัญชี Meta ควรเพิ่มเป็น PUB-10 (P0)

**9. Edit economics:** POPCONT ให้ "แก้ฟรี 1 ครั้ง" และ AI Edit Image ฟรี PRD GEN-5 (regenerate caption ฟรี 3 ครั้ง, ภาพ 0.5) แข่งได้ แต่ควรเพิ่ม text-instruction image edit (GEN-9) ขึ้นเป็น P0 ในราคา 0 หรือ 0.2 เพราะคู่แข่งให้ฟรี

**10. Payments และคุณภาพ:** POPCONT ใช้ Stripe และในคลิปมีออเดอร์ค้าง "Pending" หลายรายการ แผน PromptPay QR (BILL-2) ของเราจึงเป็นจุดต่างที่ควรสื่อ คลิป POPCONT ยังโชว์ badge "[DEV] 1 prompt" บน production ใน DESIGN/ARCHITECTURE ควรมี feature flag ที่ซ่อน debug UI ทั้งหมดใน prod

**11. Mobile-first ใช้งานจริง:** เดโมของ POPCONT ครึ่งหนึ่งถ่ายจากมือถือ (ฟอร์มยาวหน้าเดียว, เลือกรูปจาก Photos) DESIGN ควรออกแบบ Quick create, Brand wizard และ Campaign planner ให้ใช้ได้เต็มรูปแบบที่ 390px ไม่ใช่แค่ approval
