# ตรวจชื่อแบรนด์ PANGLAB (ปังแล็บ) — เครื่องหมายการค้า โดเมน และ handle

> เอกสารนี้เป็นการตรวจเบื้องต้น (knock-out search) จากแหล่งสาธารณะเท่านั้น **ไม่ใช่ legal clearance** — ก่อนลงทุนแบรนด์จริงต้องให้ตัวแทนสิทธิบัตร/เครื่องหมายการค้าค้น DIP และ WIPO อย่างเป็นทางการ
> ตรวจเมื่อ 2026-10-08 · VERIFIED = อ่านจากผลลัพธ์/แหล่งจริง · INFERRED = อนุมานจากความรู้ทั่วไป

## สรุป
ไม่พบบริษัท ผลิตภัณฑ์ หรือเครื่องหมายการค้าชื่อ "PANGLAB" / "ปังแล็บ" ที่ทำธุรกิจ marketing/AI/software จาก web search (ใกล้สุดคือแล็บวิจัยมหาวิทยาลัย "Hongbo Pang Lab" และเครื่องหมายสหรัฐฯ "PANLABS" ที่ถูกยกเลิกแล้ว) และโดเมน **panglab.ai / .co / .app / .io ยังว่าง** แต่ **panglab.com ถูกจดแล้ว** (เจ้าของ/การใช้งานตรวจไม่ได้เพราะ proxy บล็อก) ฐานข้อมูล DIP ไทยและ WIPO Global Brand DB เข้าตรวจโดยตรงไม่ได้ในรอบนี้ จึงยังถือว่า "ไม่พบ conflict ชัดเจน แต่ยังไม่ผ่านการ clear" ส่วนทางเลือก JAIBRAND มีโดเมนว่างครบทุกนามสกุล (รวม .com) ขณะที่ SAENG เป็นคำทั่วไป (แสง) ที่มีบริษัทใช้อยู่หลายราย ความเฉพาะตัวต่ำกว่า

## Social handles

## คำถามที่ยังเปิด

ผลค้น DIP และ WIPO Global Brand DB จริงในคลาส 9/35/42 ยังไม่มี (ต้องทำโดยคนหรือตัวแทน) — ใครเป็นเจ้าของ panglab.com และยอมขายหรือไม่ — panglab.co.th / .in.th ว่างหรือไม่ (ต้องเช็ก THNIC) — handle @panglab บนแต่ละแพลตฟอร์มว่างจริงหรือไม่ — จะใช้ชื่อบริษัทจดทะเบียน (DBD) เป็น "ปังแล็บ" ด้วยหรือไม่ ซึ่งต้องตรวจชื่อซ้ำกับ DBD แยกต่างหาก
