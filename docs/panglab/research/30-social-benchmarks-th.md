> รายงานวิจัย #30 สำหรับ PANGLAB · ข้อมูล ณ 2026-10-08 · ป้ายกำกับ: **VERIFIED** = อ่านจากหน้าต้นทางหรือ summary ทางการผ่าน search snippet, **INFERRED** = ตีความ/อ้างต่อจากแหล่งทุติยภูมิ, **CONFLICT** = แหล่งขัดกัน
> หมายเหตุวิธีการ: rivaliq.com, get.rivaliq.com, timetopost.co ถูก egress proxy บล็อก จึงใช้ข้อมูลจาก search snippet และแหล่งที่อ้างต่อ ตัวเลข Rival IQ ทุกตัวจึงควรตรวจกับ PDF ต้นฉบับก่อนใช้ใน UI หรือการตลาด

## สรุป
Engagement แบบ organic ของแบรนด์บน Facebook ต่ำมากและยังลดลง ค่ากลางทุกอุตสาหกรรมอยู่ที่ราว 0.05–0.15% ต่อโพสต์ ขึ้นกับผู้วัด (Rival IQ ใช้ follower เป็นตัวหาร ส่วน Socialinsider ใช้วิธีของตัวเอง) Instagram อยู่ที่ราว 0.33–0.55% โดย **carousel กับ Reels ผลัดกันนำ และภาพเดี่ยวแพ้ทั้งคู่** ยังไม่พบ benchmark ระดับอุตสาหกรรมที่เผยแพร่สาธารณะสำหรับไทยโดยเฉพาะ ข้อมูลไทยที่มีคือขนาดผู้ใช้ (NapoleonCat: FB ประมาณ 61 ล้านคน หรือ 86.6% ของประชากร) แนวโน้มประเภทคอนเทนต์จาก Wisesight และคำแนะนำเวลาโพสต์ที่ยังขัดกันเอง (เช้า 08–12 น. กับเย็น 17–21 น.) ดังนั้น PANGLAB ควรเริ่มจาก default ที่อิงงานวิจัย แล้วให้ learning loop เรียนรู้เวลาโพสต์จาก Insights ของแต่ละเพจเอง

## 5. Format ที่ได้ผลปี 2025-2026

| Format | Facebook | Instagram | ข้อสรุป |
|---|---|---|---|
| Carousel / Album | 0.18% (2025), 0.11% (Q2 2026), ดีสุดสำหรับเพจเล็ก และนำด้าน shares/views | **0.50–0.55% อันดับ 1** (Rival IQ และ Socialinsider ตรงกัน) | ควรเป็น format หลักของ SME |
| Reels / วิดีโอสั้น | 0.18% (2025), **0.13% นำใน Q2 2026** | 0.48–0.52% อันดับ 2 ไล่ใกล้มาก | ต้องมีภายใน V1 |
| ภาพเดี่ยว | 0.15% → 0.10% | 0.33–0.35% (−17% YoY) | ใช้ได้ แต่แพ้ format อื่น |
| Status / text | 0.20% (2025) แต่ตกเหลือ 0.08% ใน Q2 2026 | – | ไม่เสถียร |
| Link post | 0.05% (ต่ำสุดตลอด) | – | ควรเลี่ยง ใส่ลิงก์ในคอมเมนต์หรือ CTA แทน |

## ผลต่อ PRD

| # | ข้อเสนอ | Requirement ที่เกี่ยวข้อง |
|---|---|---|
| 1 | ตั้ง **Album/Carousel เป็น format default** ของ Quick Post และ Campaign สำหรับ IG และเพจเล็ก (ภาพเดี่ยวเป็นตัวเลือกรอง) | GEN-4 (คง P0), PUB-3 |
| 2 | ขยับ **Reels/วิดีโอสั้นจาก P1 ไปเป็น P0 ต้น V1** เพราะเป็น format นำบน FB ปี 2026 และอันดับ 2 บน IG | PUB-8 |
| 3 | เพิ่ม requirement ใหม่ **CAL-x "Smart slot default"**: ตั้งเวลาเริ่มต้นเป็น 2 slot ตามเวลาไทย (ICT) คือ 09:00 และ 19:00 น. วันจันทร์–ศุกร์ และบอกผู้ใช้ว่าเป็นค่าเริ่มต้นจากงานวิจัย ไม่ใช่ค่ารับประกัน | CAL-1, CAMP-4 |
| 4 | ทำ CAMP-5 learning loop ให้ **A/B เวลาโพสต์เช้ากับเย็น** ภายใน 2–4 สัปดาห์แรกของแต่ละเพจ แล้วปรับ slot อัตโนมัติ (ต้องมี ANA-1 ครบ 7 วัน) | CAMP-5, ANA-1 |
| 5 | ตั้ง **ความถี่เริ่มต้นของแผน**: FB 4–5 โพสต์/สัปดาห์ และ IG 3–4 โพสต์/สัปดาห์ ผู้ใช้ปรับได้ และใช้ตัวเลขนี้ประมาณการเครดิตต่อเดือนใน pricing | GEN-2, Campaign Studio |
| 6 | ตั้ง **pillar mix default ตามเทรนด์ไทย**: entertainment/สูตร-DIY/how-to ≥ 50% และ promo ≤ 30% (Wisesight ชี้ว่า promo −18%) | GEN-2, CAMP-5 |
| 7 | หน้า Analytics ควรแสดง **benchmark band** เช่น "FB เพจทั่วไป 0.05–0.15%, IG 0.3–0.55%" พร้อมระบุแหล่งที่มา เพื่อไม่ให้ SME ตกใจกับ ER ต่ำ และควรเทียบกับค่าเฉลี่ยของเพจตัวเองเป็นหลัก | ANA-1, roadmap "Best-time + pillar insights" |
| 8 | เตือนในตัวสร้างโพสต์เมื่อใส่ลิงก์ใน body ของ FB (link post ER 0.05%) และแนะนำให้ใช้ภาพพร้อม CTA แทน | GEN (caption rules) |

## คำถามที่ยังเปิด
1. ตัวเลขค่ากลาง FB ของ Rival IQ 2025 คือ 0.046% หรือ 0.063% ต้องอ่าน PDF ต้นฉบับ (proxy บล็อก) ให้ทีมเปิดด้วย browser
2. ยังไม่มี benchmark ER รายอุตสาหกรรมของไทยที่เปิดสาธารณะ ควรตรวจว่า Wisesight, DataXet หรือ Socialinsider (ฟิลเตอร์ประเทศ, ต้องจ่ายเงิน) ขายข้อมูลระดับประเทศหรือไม่
3. เวลาโพสต์ไทยเช้า (Content Shifu) กับเย็น (timetopost, Relevant Audience) ต่างกันเพราะเหตุใด อาจเป็นเพราะคนละอุตสาหกรรมหรือคนละ metric (reach กับ engagement) ควรใช้ข้อมูล beta 20 แบรนด์ตอบ
4. ใน Q2 2026 engagement บน FB ตกทุก format ควรติดตามว่าเป็นผลจากการเปลี่ยน algorithm ของ Meta หรือเป็นฤดูกาล
5. Meta นับ engagement/reach ของ AI-generated content ต่างจากคอนเทนต์ทั่วไปหรือไม่ (ดูรายงาน #11)
