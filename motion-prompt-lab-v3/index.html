Not configured

Personal/static use: Key ถูกเก็บใน localStorage ของ browser นี้ และ request ถูกส่งตรงไป Google Gemini API. สำหรับเว็บ public/production ควรย้าย key ไป server-side proxy / environment variable เพราะ client-side key สามารถมองเห็นจาก DevTools ได้

Request ที่เว็บใช้

POST https://generativelanguage.googleapis.com/v1beta/models/{MODEL}:generateContent
Header: x-goog-api-key: YOUR_KEY
Body: contents + systemInstruction + generationConfig
